# 🏥 Hospital Bed Allocation and Availability Monitoring System

## 📌 Project Overview

The **Hospital Bed Allocation and Availability Monitoring System** is a digital healthcare management solution designed to simplify and improve the process of managing hospital beds. It helps hospitals monitor bed availability, allocate beds to patients, and manage occupancy information efficiently.

The system aims to reduce manual workload, minimize delays in bed allocation, and provide real-time information about available, occupied, and reserved beds.

## 🎯 Objectives

- Monitor hospital bed availability efficiently.
- Simplify the bed allocation process.
- Maintain accurate patient and bed records.
- Reduce manual paperwork and administrative workload.
- Improve hospital resource management.
- Help hospital staff make faster bed allocation decisions.

## ✨ Key Features

- **Bed Availability Monitoring:** View available, occupied, and reserved beds.
- **Patient Registration:** Maintain patient information and admission records.
- **Bed Allocation:** Allocate suitable beds to patients.
- **Bed Status Management:** Update bed status whenever a patient is admitted or discharged.
- **Patient Management:** Manage patient admission and discharge details.
- **Dashboard:** View important hospital bed statistics.
- **Efficient Management:** Reduce manual errors and improve workflow.

## ⚙️ System Workflow

1. Hospital staff register patient details.
2. The system checks the availability of hospital beds.
3. An available bed is selected and allocated to the patient.
4. The bed status is updated automatically.
5. When the patient is discharged, the bed becomes available again.
6. Staff can monitor bed availability through the system dashboard.
